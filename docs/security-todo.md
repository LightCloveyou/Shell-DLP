## 当前静态分析边界

- 动态计算的默认值、任意对象转换、复杂控制流和外部程序配置无法由静态参数模型完整求值。缺失项使用 Information missing；若同一命令存在独立、确定的敏感流，仍执行规则阻断。
- no-match 只表示配置的匹配器在已覆盖范围内未命中，不代表内容安全。未知或自定义编码没有通用还原保证。
- 管道完成前，工作项的未确认状态仍只在进程内；另一个进程并发访问、写进程崩溃、互斥超时或磁盘失败不属于正常完成的提交保证。未验证发布者身份，也不把同名二进制视为已认证。

## 流程图执行规则

- 逐阶段绑定输入、传播数据、记录外发证据。上一阶段未知只影响依赖它的输入；新的独立数据源可以开始新的传播链，不依赖 A–F 的位置。
- 已确认外发后继续检查本 ScriptBlock 其余语句；汇总最终决定，单独报告后续敏感来源和外发。仅本地读取敏感文件不是阻断理由。
- 请求的响应内容与会话状态变化分开。只失效明确的输出文件、输出变量；不明写入才失效可能受影响的会话证据。
- 这部分实现的是 PowerShell AST 的 Source → Propagation → Sink 路径；原图中 GUI/服务的探针、风险模型和 hook 是其他阶段。
