# Shell DLP

本项目正在将原有的 Linux eBPF 实现迁移到 Frida，以便在不同平台上对命令执行和数据外传路径进行动态监控与策略拦截。

## 当前状态

迁移工作仍在进行中。目前已经完成并成功验证以下场景：

- Git 命令与 `git push` 拦截
- SCP 文件传输监控
- Python 进程及相关命令监控
- 其他部分常用命令执行路径

## 进行中的工作

其余程序和命令路径仍在迁移、修复与兼容性调整中，部分场景可能存在性能、进程接入、退出清理或误拦问题。

当前实现需要继续进行手动验证，重点检查：

- 目标进程是否成功接入 Frida
- 普通命令是否正常放行
- 敏感操作是否按策略阻断
- 后台退出后相关命令是否恢复正常
- 不同终端、Shell 和子进程启动方式下的行为是否一致

在完成全部手动验证前，请将当前版本视为迁移中的测试版本。

## 已验证示例

Git/Frida 验证实现位于：

```text
demo/frida_git_guard
```

该示例包含策略配置、Frida 后台、进程启动拦截脚本、自动化测试、现场验证记录与回滚工具。
